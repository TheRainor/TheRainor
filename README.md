## ⚡ Featured Ecosystems

### 🎙️ **Cleivra** — Real-Time Voice & Text Communication Platform
A highly scalable, production-ready Discord alternative built to handle low-latency real-time data streaming and media room management.
* **Live App:** [cleivra.vercel.app](https://cleivra.vercel.app)
* **Architecture & Highlights:**
  * **Media & Streaming:** Integrated **LiveKit (Client & Server SDK)** to handle robust, scalable WebRTC voice/video rooms.
  * **Real-Time Engine:** Powered by **Socket.io** for persistent bi-directional messaging and event orchestration.
  * **Frontend & Caching:** Built on the bleeding edge of **Next.js 16**, **React 19**, and **Tailwind CSS v4**, utilizing **Zustand** for state management and **TanStack Query (v5)** for server state synchronization.
  * **Backend & Persistence:** Driven by **Express 5** connected to a high-performance **PostgreSQL** database, featuring type-safe queries via **Prisma ORM** with reliable asset pipelines handled through **UploadThing** and **Sharp**.

---

### 📅 **TaskProse** — Unified Cross-Platform Task Management
A comprehensive, end-to-end task ecosystem deployed seamlessly across Web, Desktop, and Mobile environments from a unified architecture.
* **Live App:** [taskprose.vercel.app](https://taskprose.vercel.app)
* **Architecture & Highlights:**
  * **Creative Frontend (Web):** Developed using **Vite 7** and **React 19**, featuring rich interactive layouts and high-performance 3D visual elements leveraging **Three.js**, **OGL**, and **GSAP** animations.
  * **Desktop Client:** Packaged and distributed via **Electron 37** and **Electron Builder** with production-optimized native installer configurations.
  * **Mobile Client:** Native application compiled using **Expo 53** and **React Native 0.79**, styled with utility-first layouts using **NativeWind v4** and secured with biometric workflows via **Expo Local Authentication**.
  * **Backend Infrastructure:** Supported by an **Express 5** API layer connected to a persistent **MySQL** database, with automated background routines managed through **Node-Cron**.
